# qr-equipment-system
1주차 : QR기반 공용 기자재예약·반납 시스템 기획서
1. 프로젝트 개요
프로젝트명 : QR 기반 공용 기자재예약·반납 시스템
목적 : 학과 공용 기자재의 분리/반납 수기 작성을 편안하게 하고, QR 코드를 활용하여 사용할 수 있는 상태 관리 시스템 구축
2. 버거사용자 (페르소나)
일반 사용자(학생) : 학과 기자재(카메라, 노트북, 개발 키트 등)를 신속하게 처리/반납하고자 하는 사용자
관리자(학과 조교/학생회) : 기자재 수량, 비중/반납 상태, 연체 목록을 통합관리하고자 하는 사용자
3. 1차 MVP (최소 기능 제품) 개발 스코프
모바일 카메라 기반 QR 코드 검색 및 식별
열대야 및 반납 처리
주요 상태 조회(대여 가능성/중요/연체)
사용자 정의 이력 조회 (마이페이지)
관리자 기자재 CRUD 및 현황 모니터링
