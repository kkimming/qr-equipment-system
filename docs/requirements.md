# 1주차: QR 기반 공용 기자재 예약·반납 시스템 기획서

## 1. 프로젝트 개요
* **프로젝트명**: QR 기반 공용 기자재 예약·반납 시스템
* **목적**: 학과 공용 기자재의 오프라인 대여/반납 수기 작성 불편함을 해소하고, QR 코드를 활용한 실시간 대여 상태 관리 시스템 구축

## 2. 타겟 사용자 (Persona)
* **일반 사용자 (학생)**: 학과 기자재(카메라, 노트북, 개발 키트 등)를 신속하게 대여/반납하고자 하는 사용자
* **관리자 (학과 조교/학생회)**: 기자재 수량, 대여/반납 상태, 연체 목록을 통합 관리하고자 하는 사용자

## 3. 1차 MVP (최소 기능 제품) 개발 스코프
* [x] 모바일 카메라 기반 QR 코드 스캔 및 식별
* [x] 실시간 기자재 대여 및 반납 처리
* [x] 대여 상태 조회 (대여 가능 / 대여 중 / 연체)
* [x] 사용자 대여 이력 조회 (마이페이지)
* [x] 관리자 기자재 CRUD 및 대여 현황 모니터링
